# fleet - configuration

The capability-routed fleet matrix. Every file states its own provenance and
carries only receipt-backed values; unreceipted numbers are explicit nulls
(Constitution Article 5).

- providers.yaml - the provider rows SIGMA routes on: local lanes, the one
  proof-backed enrolled lung (with the FALSIFIED routing verdict and its
  capability rows verbatim), and the mlx-cluster anchor that enrollment
  inserts above. Estate file carried 30+ cloud rows; they stay estate-side.
- seat_allowlist.json - PUBLIC Ed25519 node keys only, each naming its
  receipt; the two aspire-surface keys are pointed at, never guessed.
- sigma_fleet_envelopes.yaml - RAM ceilings, thermal limits, duty bands per
  node; the v2 re-landing of the aspire-side envelope plane.
- lanes.yaml - the lane ladder (L0 local janitor first), the local model
  doctrine, and the hardware envelope.

Consumer: organs/cost-priced (device classes match the watt rows),
organs/consent-gated-join/fleet_enroll.py (writes providers.yaml above the
mlx-cluster anchor), organs/fleet-visible/fleet_door.py (enrolled-lung rows).
Verifier: the consuming organs' test suites parse these files.
